# Portfolio Website - PPW Week 2

## 📌 Deskripsi

Repository ini merupakan hasil pengerjaan Praktikum Minggu 02 pada mata kuliah **Pemrograman dan Pengujian Aplikasi Web (PPW)**.

Website ini merupakan personal portfolio sederhana yang dibuat menggunakan **HTML5 dan CSS3** dengan menerapkan konsep semantic HTML, responsive design, accessibility, serta modern web interface.

Website menampilkan informasi profil mahasiswa, portofolio proyek, keahlian, serta formulir layanan atau konsultasi.
